╔═══════════════════════════════════════════════════════════════╗
║  KEYBINDINGS (Qtile)                                          ║
╚═══════════════════════════════════════════════════════════════╝

  PRIMARY LAUNCHER
  ────────────────
  Super + Space         → All-in-one launcher (combi mode)
  Super + Shift + Space → Unified menu alternative

  QUICK ACCESS
  ────────────
  Super + D             → Applications
  Super + R             → Run command
  Super + W             → Window switcher
  Super + E             → File browser

  UTILITIES
  ─────────
  Super + X             → Power menu
  Super + V             → Clipboard history
  Print                 → Screenshot menu
  Super + N             → Network manager
  Super + Shift + S     → Settings menu

  BONUS
  ─────
  Super + C             → Calculator
  Super + .             → Emoji picker

╔═══════════════════════════════════════════════════════════════╗
║  NAVIGATION (Inside Rofi)                                     ║
╚═══════════════════════════════════════════════════════════════╝

  MOVEMENT
  ────────
  ↑/↓ or Ctrl+P/N       → Navigate up/down
  Tab                   → Next mode
  Shift + Tab           → Previous mode
  Home/End              → First/last item
  PgUp/PgDn             → Page up/down

  ACTIONS
  ───────
  Enter                 → Select/execute
  Shift + Enter         → Alternative action
  Ctrl + Enter          → Custom action
  Delete                → Remove history entry
  Esc or Ctrl+G         → Close/cancel

  EDITING
  ───────
  Ctrl + A              → Move to start
  Ctrl + E              → Move to end
  Ctrl + W              → Delete word
  Ctrl + U              → Clear line
  Alt + Left/Right      → Word navigation

╔═══════════════════════════════════════════════════════════════╗
║  FILE LOCATIONS                                               ║
╚═══════════════════════════════════════════════════════════════╝

  ~/.config/rofi/config.rasi              → Main config
  ~/.config/rofi/scripts/                 → Utility scripts
  ~/.config/rofi/themes/                  → Custom themes
  ~/Pictures/Screenshots/                 → Screenshots

╔═══════════════════════════════════════════════════════════════╗
║  COMMAND LINE USAGE                                           ║
╚═══════════════════════════════════════════════════════════════╝

  rofi -show combi                        → All-in-one launcher
  rofi -show drun                         → Applications
  rofi -show run                          → Run command
  rofi -show window                       → Windows
  rofi -show filebrowser                  → File browser
  rofi -show ssh                          → SSH connections
  rofi -show calc -modi calc              → Calculator
  rofi -show emoji -modi emoji            → Emoji picker

  WITH CUSTOM THEME
  ─────────────────
  rofi -show combi -theme ~/.config/rofi/themes/minimal.rasi

╔═══════════════════════════════════════════════════════════════╗
║  POWER MENU OPTIONS                                           ║
╚═══════════════════════════════════════════════════════════════╝

  ⏻  Shutdown           → Power off system
    Reboot             → Restart system
    Lock               → Lock screen
  ⏾  Suspend            → Suspend to RAM
    Hibernate          → Suspend to disk
    Logout             → Exit Qtile

╔═══════════════════════════════════════════════════════════════╗
║  SCREENSHOT OPTIONS                                           ║
╚═══════════════════════════════════════════════════════════════╝

    Fullscreen         → Capture entire screen
    Area               → Select area to capture
    Window             → Capture active window
    Delay 5s           → 5 second delayed capture
    Delay 10s          → 10 second delayed capture

  Screenshots saved to: ~/Pictures/Screenshots/
  Auto-copied to clipboard

╔═══════════════════════════════════════════════════════════════╗
║  NETWORK MANAGER                                              ║
╚═══════════════════════════════════════════════════════════════╝

    WiFi On/Off        → Enable/disable WiFi
    Connect WiFi       → Scan and connect to network
    Disconnect         → Disconnect current network
    Ethernet Status    → Show ethernet info
    VPN Status         → Show VPN connections
  ✈  Airplane Mode      → Toggle all wireless

╔═══════════════════════════════════════════════════════════════╗
║  SETTINGS MENU                                                ║
╚═══════════════════════════════════════════════════════════════╝

    Display            → Screen resolution/arrangement
    Audio              → Volume/device control
    Bluetooth          → BT device management
  ⌨  Keyboard           → Layout switching
    Theme              → Rofi theme selector
    Appearance         → GTK/Qt themes
    Notifications      → Dunst toggle
    Compositor         → Picom toggle

╔═══════════════════════════════════════════════════════════════╗
║  CALCULATOR MODE                                              ║
╚═══════════════════════════════════════════════════════════════╝

  OPERATORS
  ─────────
  +  -  *  /            → Basic operations
  ^                     → Power
  %                     → Modulo
  sqrt(x)               → Square root
  sin(x) cos(x) tan(x)  → Trigonometry
  log(x) ln(x)          → Logarithms

  Result auto-copies to clipboard

╔═══════════════════════════════════════════════════════════════╗
║  TROUBLESHOOTING                                              ║
╚═══════════════════════════════════════════════════════════════╝

  No icons showing
  ────────────────
  → sudo pacman -S papirus-icon-theme
  → gtk-update-icon-cache

  Clipboard not working
  ─────────────────────
  → clipmenud &  (in autostart)

  Transparency not working
  ────────────────────────
  → picom -b  (in autostart)

  Network menu fails
  ──────────────────
  → sudo systemctl enable --now NetworkManager
